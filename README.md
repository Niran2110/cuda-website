# CUDA - Creative Portfolio Website

A responsive creative portfolio and agency website developed using HTML5 and CSS3.

## 📌 Project Overview

CUDA is a responsive portfolio website featuring services, team members,
skills, portfolio projects, client testimonials and a contact section.

## ✨ Features

- Responsive navigation
- Hero section
- Services section
- Team members section
- Skills and progress indicators
- Portfolio section
- Client testimonials
- Contact form
- Social media links
- Responsive layout for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Responsive Web Design
- CSS Media Queries

## 📱 Responsive Design

The website is designed for:

- Mobile devices
- Tablets
- Laptops
- Desktop screens
